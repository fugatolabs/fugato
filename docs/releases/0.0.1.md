# Fugato 0.0.1

Release notes prepared for macOS/Linux on AMD64 and ARM64. Fugato manages
local Git-worktree environments using existing native commands, Docker Compose,
or both. The CLI includes a local daemon; the separate stdio MCP binary lets
agents inspect and manage the same environments. The optional Cursor VSIX adds
worktree controls, logs, and preview links.

- Configure explicit startup, named commands/checks, and preview endpoints in
  `.fugato.yaml`; inspect setup with `fugato doctor` before starting work.
- Copy declared ignored local inputs into an existing worktree with a preparation
  preview; preserve existing files and keep secrets out of repository config.
- Run and stop workloads, inspect port bindings, and explicitly clean up owned
  runtime data when needed.

Download the archive matching your platform. `install.sh` verifies the archive
using `checksums.txt` and installs both executables into `~/.local/bin`. Full
licenses and third-party notices are inside every archive. The optional
`fugato-0.0.1.vsix` is installed manually in Cursor. See
[installation](https://github.com/fugatolabs/fugato/blob/main/docs/guides/install.md),
[agent quickstart](https://github.com/fugatolabs/fugato/blob/main/docs/guides/agent-quickstart.md),
and [distribution details](https://github.com/fugatolabs/fugato/blob/main/docs/distribution.md).

Version 0.0.1 has no stable compatibility promise. Cross-built assets do
not establish runtime testing on every target. Packages are unsigned and macOS
binaries are not notarized. Docker and application-specific dependencies are
installed separately; native-only projects do not require Docker. There is no
Marketplace or Open VSX publication. Configuration schema version 1, local API
v1, and MCP protocol versions are independent of the 0.0.1 product version.
