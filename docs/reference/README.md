# Reference

The [local project contract](project.md) covers Compose discovery, optional configuration, ports, data, resource limits, and `doctor` findings. The [environment contract](environment.md) covers native commands, mixed projects, optional browser endpoints, and the setup-agent prompt. The [configuration schema](fugato.schema.json) supports editor completion and structural validation; `doctor` also checks references and runtime requirements. The [MCP reference](mcp.md) covers agent tools and verification.

Daemon contributors should also read the [lifecycle and resource decisions](../architecture/daemon-lifecycle.md).
